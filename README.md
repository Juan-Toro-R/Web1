# 🚀 Web 1 - Desarrollo Web
### Ingeniería Informática | Universidad de Caldas

¡Bienvenido! Este repositorio está dedicado al almacenamiento y organización de las prácticas, laboratorios y proyectos desarrollados a lo largo de la asignatura de **Web 1**.

---

## 📂 Proyectos y Contenido del Repositorio

A continuación se detallan los módulos y aplicaciones desarrolladas en este curso:

* **🎬 `cine-explorer/`**: Aplicación para la exploración y búsqueda de películas consumiendo una API externa.
* **💼 `portafolio/`**: Proyecto de marca personal y exhibición de trabajos y proyectos.
* **📄 `HojaDeVida/`**: Maquetación de currículum vitae utilizando estructura semántica en HTML5.
* **📥 `inputs/`**: Ejercicios prácticos sobre formularios, validaciones y captura de datos.
* **📐 `posicionamiento/`**: Prácticas avanzadas de maquetación y diseño responsivo usando Flexbox y CSS Grid.
* **📊 `Tabla/`**: Estructuración, diseño y diseño estilizado de tablas de datos.
